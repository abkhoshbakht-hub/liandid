# ماژول صفحه اول روزنامه‌ها

دریافت، آرشیو و نمایش خودکار جلد روزنامه‌ها — یکپارچه با معماری فعلی لیان‌دید
(Next.js + Prisma + PostgreSQL + Sharp، بدون وابستگی جدید).

## نصب و راه‌اندازی

1. دیپلوی معمول (مایگریشن در `prisma/migrations/20260908120000_add_newspapers/`).
2. ورود ادمین → سایدبار → مدیریت → **صفحه اول روزنامه‌ها** → دکمه
   **راه‌اندازی جداول + ثبت ۱۴ روزنامه** (یک بار؛ چون دیتابیس از بیرون در دسترس نیست).
3. همین صفحه، تب **داشبورد** → **اجرای دریافت امروز** برای تست.

## Environment Variables

- `DATABASE_URL` — همان دیتابیس اصلی (جدید لازم نیست).
- `BLOB_READ_WRITE_TOKEN` — اختیاری؛ اگر باشد جلدها در Vercel Blob ذخیره می‌شوند،
  وگرنه در دیتابیس (base64). بدون نیاز به حساب خارجی کار می‌کند.
- `CRON_SECRET` — استفاده نمی‌شود (محافظ کرون با `newspapers:lastCron` است).

## Database

مدل‌ها در `prisma/schema.prisma`: `Newspaper` / `NewspaperSource` / `NewspaperIssue` /
`NewspaperFetchLog`. یونیک `newspaperId + date` مانع شماره تکراری است.

## Seed

`src/lib/newspapers/seed.ts` — ۱۴ روزنامه. سایت‌ها فقط موارد تأییدشده (HTTP 200).
**قانون: هیچ URL حدسی سید نمی‌شود.** سورس خودکار تأییدشده فقط کیهان است
(الگوی `files/fa/publication/pages/...jpeg` در صفحه اصلی).

## Cron

`vercel.json` → هر روز `30 2 * * *` (۶:۰۰ تهران) به `/api/cron/newspapers`.
محافظ اجرای تکراری: اگر کمتر از ۲۰ ساعت از اجرای قبلی گذشته باشد رد می‌شود.
اجرای دستی ادمین: `GET /api/cron/newspapers?now=1` (با سشن ادمین).

## Storage

`src/lib/newspapers/storage.ts` — اینترفیس `CoverStorage` با دو پیاده‌سازی
`DbCoverStorage` و `BlobCoverStorage`. افزودن S3/R2/MinIO = یک کلاس جدید + یک خط در
`getCoverStorage()`. مسیر پیشنهادی: `newspapers/<slug>/<date>/<kind>.webp`.

## اضافه کردن روزنامه

پنل → تب روزنامه‌ها → **+ افزودن روزنامه** (نام، نامک انگلیسی، دسته). بدون تغییر کد.

## اضافه کردن Source

پنل → انتخاب روزنامه → **+ افزودن سورس**:
- `official` — سایت رسمی (`pageUrl` + اختیاری `imgPattern` regex + `keywords`)
- `telegram` — کانال رسمی (`{"telegram_channel":"hamshahri"}` یا URL کامل `t.me/...`)
- `news_agency` / `other` — منبع خبری معتبر
- `manual` — فقط آپلود دستی (در موتور خودکار نادیده گرفته می‌شود)

`priority` کمتر = اول. دکمه **تست** هر سورس را بدون ذخیره امتحان می‌کند.

## ساخت Adapter جدید

`src/lib/newspapers/adapters.ts` — کلاس جدید با متد `fetchCandidate()` که
`CoverCandidate` برگرداند + یک خط در `getAdapter()`. مثال: `ManualAdapter`.

## Manual Upload

تب شماره‌ها → انتخاب روزنامه + تاریخ + عکس → **ثبت دستی** (وضعیت PUBLISHED، منبع MANUAL).
جایگزینی عکس هر شماره با دکمه **جایگزینی**.

## امتیاز اطمینان

تطابق تاریخ +۴۰، نام +۲۵، منبع رسمی +۲۰، ابعاد +۱۰، پرتره +۵.
۹۰+ انتشار خودکار، ۷۰–۸۹ نیاز به بررسی، کمتر رد/بررسی دستی.

## APIها

عمومی: `GET /api/newspapers` ،`/today` ،`/archive` ،`/:slug` ،`/:slug/issues`
مدیریت: `/api/admin/newspapers/...` (جداول، سورس‌ها، شماره‌ها، لاگ‌ها، آمار، دریافت، تست)

## Deployment

پوش به main = دیپلوی خودکار ورسل. بعد از اولین دیپلوی، دکمه راه‌اندازی در پنل.

## Troubleshooting

- «سورس فعالی تنظیم نشده» → برای آن روزنامه سورس فعال اضافه کن.
- `no-cover-post-today` (تلگرام) → کانال امروز پست جلد نگذاشته یا کپشن کلمه «صفحه اول/جلد» ندارد.
- جلد اشتباه منتشر شد → تب شماره‌ها → رد + جایگزینی دستی.
- کرون اجرا نشد → تب داشبورد زمان «آخرین کرون» را ببین؛ دستی اجرا کن.
